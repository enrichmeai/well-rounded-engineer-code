# Well Rounded Engineer: code

The craft of code: the Java 8 to 25 tour, Python idioms, design patterns, testing and refactoring.

This repository holds small, runnable examples for the free guide
[Well Rounded Engineer — More Human](https://enrichmeai.com/well-rounded-engineer/). Every concept in the guide
links to a folder here, and every folder can be run on a laptop, with no cloud account and no paid tools.

## How it is organised

| Folder | What it shows | Read first |
|---|---|---|
| [`java/`](java/) | Java, release by release | [guide](https://enrichmeai.com/well-rounded-engineer/java/) |
| [`python/`](python/) | Python idioms | [guide](https://enrichmeai.com/well-rounded-engineer/python/) |
| [`patterns/`](patterns/) | Design patterns (Gang of Four) | [guide](https://enrichmeai.com/well-rounded-engineer/history/) |
| [`testing/`](testing/) | Testing: unit, browser, API and load | [guide](https://enrichmeai.com/well-rounded-engineer/testing/) |
| [`refactoring/`](refactoring/) | Refactoring | [guide](https://enrichmeai.com/well-rounded-engineer/testing/) |

Each folder has its own README: what it shows, how to run it, what to try next, and what to read. Each example has
tests, and CI runs them on every change, so the code here keeps working.

Folders are added one pull request at a time. A folder listed above without content yet is planned.

## Why this exists

A click is cheaper than a prompt. For what is already known, read the guide and run the example; use AI where it
earns its keep. Read [why this guide exists](https://enrichmeai.com/well-rounded-engineer/why/).
